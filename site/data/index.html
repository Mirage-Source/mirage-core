What was changed before publishing

  • SSH and telnet sessions keep the real source IP. Every connection to these ports is unsolicited and almost all of it is automated; the address is the attack infrastructure researchers need. Many are hijacked devices on home networks, so an address identifies a compromised machine, not its owner's intent.
  • Commands and HTTP events hash every IP with the same salted HMAC, so the two sensors can be joined on client_ip / ip without publishing the address. The HTTP sensor's site is also browsed by people.
  • HTTP requests that are not attacks lose their cookies, authorization headers and bodies. Requests the classifier labels as attacks are kept whole: there the headers and body are the payload. Reverse DNS is kept only for verified crawlers.
  • The sensors' own trap tokens and planted credentials are removed, so they cannot be replayed into the data. An event that could not be cleaned is dropped and counted in the manifest.
  • Secret-shaped strings in commands (private keys, cloud keys, email addresses, long hex tokens) are redacted. Do not try to re-identify individuals or reverse the hashed addresses.
